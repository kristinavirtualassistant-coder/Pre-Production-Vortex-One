# Vortex One marketing website

Static site (no build step) for `www.remoteaccountmanagers.online` (until that domain is live, use the free Vercel URL), hosted on Vercel.
Vercel project settings: Root Directory `website`, Framework Preset `Other`, no build command, output `.`.
Sign-up and sign-in buttons link to the platform at `vortex-one-web.onrender.com` (switch to `app.remoteaccountmanagers.online` once the domain is live) (`?signup=1` opens the sign-up form).
Colors, type and spacing come from the Vortex One design system tokens. Pricing mirrors `server/services/billingService.ts`.
