# Vortex One marketing website

Static site (no build step) for `www.remoteaccountmanagers.online`, hosted on Vercel.
Vercel project settings: Root Directory `website`, Framework Preset `Other`, no build command, output `.`.
Sign-up and sign-in buttons link to the platform at `app.remoteaccountmanagers.online` (`?signup=1` opens the sign-up form).
Colors, type and spacing come from the Vortex One design system tokens. Pricing mirrors `server/services/billingService.ts`.
